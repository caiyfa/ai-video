# 项目区 🎬

每部漫剧作品一个独立子目录。立项时按下面的模板创建。

## 项目目录模板

```
projects/〈项目名〉/
├── README.md          # 项目简介、进度、发布记录
├── 剧本/
│   ├── 大纲.md
│   └── EP01.md ...    # 每集一个文件
├── 角色设定/          # 角色设定图 + 固定提示词模板（最重要！）
│   └── 角色-林晚.md   # 含：外貌模板、服装、声音音色、性格备忘
├── 场景设定/          # 场景设定图 + 固定提示词模板
├── 分镜/
│   └── EP01-分镜表.md # 镜头号/景别/运镜/台词/提示词/时长
├── 素材/              # 生成的图片、视频片段（按集分文件夹）
└── 成片/              # 最终导出的视频
```

## 项目 README 模板

```markdown
# 〈项目名〉

- 一句话简介：
- 题材/风格：
- 目标平台：
- 状态：剧本 / 制作中 / 已发布EP xx

## 进度
| 集数 | 剧本 | 分镜 | 成片 | 发布 |
|---|---|---|---|---|

## 发布数据记录
| 日期 | 平台 | 播放 | 完播率 | 备注 |
|---|---|---|---|---|
```

## 立项流程

1. 从 `ideas/` 挑一条灵感，让 AI 发展成故事大纲
2. 创建项目目录，写好 README 和第一版大纲
3. 先做角色设定 + 场景设定（复用性最高，值得花时间打磨）
4. 再做 EP01 全流程，跑通后进入连载节奏
