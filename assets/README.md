# 公共素材库 🎨

跨项目可复用的素材（角色、场景、风格模板），与 `projects/` 下项目私有的素材区分开。

## 目录规划

```
assets/
├── 角色/             # 通用角色库（龙套、配角、NPC）
├── 场景/             # 通用场景库（教室、街道、办公室……）
├── 风格模板/          # 验证过效果好的画风提示词模板
│   └── 战锤黑暗史诗风/   # 战锤小说参考素材包（书单/世界观/生图提示词/台词与改编套路，含版权提示）
├── 音效BGM清单.md     # 记录好用的合规曲库曲目
└── 提示词片段/        # 常用提示词组件（光影、构图、情绪动作描写）
```

## 约定

- 每个角色/场景一个 `.md` 文件：放提示词模板 + 代表图（图片放同目录或子目录）
- 图片命名：`角色名-场景-编号.png`（如 `林晚-教室-03.png`）
- 提示词模板必须与图片配套保存——模板丢了，角色就丢了
