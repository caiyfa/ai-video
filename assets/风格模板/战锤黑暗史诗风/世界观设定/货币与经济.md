# 货币与经济

> 更新：2026-10-28 ｜ 自写整理。帝国没有统一货币——"经济的碎片化"本身就是设定

## 一、战锤40K：帝国的钱

| 货币 | 适用范围 | 说明 |
|------|---------|------|
| **王座币 / 王座盖尔特**（Throne Gelt / Gelt） | 最接近"帝国通用币"：发达星区间的贸易结算币 | 荷鲁斯之乱时代已出现；硬币铸双头鹰纹。黑图书馆小说里最常出现的"钱"就是它 |
| 克朗（Crowns） | 部分星区/星球的地方货币 | 小说中常见的另一称呼 |
| 信用点（Credits） | 巢都世界（如奈克罗穆达）的城市货币 | 底层人一辈子摸不到真正的金币 |
| 实物/配给券 | 帝国卫队士兵、巢都底层——**工资常以配给形式发放** | "你月薪=三箱蛋白膏+一份燃料配额" |
| 以物易物 | 封建世界、死亡世界——钱没用，刀、水、药才是钱 | 死亡世界里"子弹比命贵" |

### 核心设定逻辑（写市井戏必读）

1. **帝国不关心钱，只关心税**（见《帝国体制与什一税》）——行政部的账本上没有"利润"只有"上缴"。金融在帝国是**地方事务**
2. **跨星贸易靠行商浪人**（Rogue Trader）：持有帝皇亲签宪章的星际商人贵族，垄断跨界贸易与未知星域开拓——发财与送命都在边疆
3. **巢都经济**：上层住云顶塔楼用王座币，中层用信用点，底层用配给券和黑市——**垂直的阶级就是垂直的货币体系**
4. **黑市**：异形Artifact、禁书、灵能道具——审判庭与走私犯的永恒猫鼠

## 二、中古战锤（Fantasy）

| 货币 | 说明 |
|------|------|
| 金克朗（Gold Crown） | 通行硬通货——旧世界的"美元" |
| 银先令（Silver Shilling） | 日常找零 |
| 黄铜便士（Brass Penny） | 底层货币；"为了几个铜板"是流氓打架的标准理由 |

- 帝国商行、赌坊、赏金制度齐全——巫师猎人赏金、兽人头颅悬赏，是冒险者经济的主轴
-矮人金矿+矮人银行的信用（矮人一诺千金是字面意义）——"矮人的账本"可以当剧情道具

## 三、西格玛时代（AoS）

- **以太金（Aether-Gold）**：卡拉德隆空霸的硬通货兼飞行燃料——"钱就是燃料"的蒸汽朋克经济
- 自由城市流通各自的城邦铸币；界门贸易（过路费天价）造就门阀商会
- 西格玛新世界"神铸货币"与灵魂交易（灵魂=终极硬通货，纳垢与奸奇都在收购）

## 四、剧本应用模板

- **一句台词建世界观**："这枚王座币在我的星球能买一头牛，在这里只够买它沾过的一格空气。"——跨星汇率差立即立体
- **交易冲突三宝**：黑市异形货（违法张力）、假币（悬疑）、以物易物世界的"钱无用"（文明冲突）
- **阶级速写**：伸手要王座币的乞丐 vs 用配给券换水的巢都人 vs 从没见过钱的封建农民——三个镜头三个世界
