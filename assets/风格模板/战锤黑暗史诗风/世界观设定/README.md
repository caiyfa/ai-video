## 使用建议

- 写剧本遇到"这东西叫什么"→ 先查本目录，避免自造名词与官方撞车或穿帮
- 正式发布时仍然走原创化改名（见 `../03-视觉风格与生图提示词.md` 替换词表），本目录用于**内部理解**
- 逻辑优先级：主剧本 > 本设定库 > 网络考据（漫画剧不是考据剧，服务故事第一）
