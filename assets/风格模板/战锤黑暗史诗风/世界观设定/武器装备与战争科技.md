# 武器装备与战争科技（四时代速查）

## 一、战锤40K（M41）单兵武器

| 武器 | 特点 | 剧本用法 |
|------|------|---------|
| 激光枪（Lasgun） | 帝国卫队标配，充电式、耐用、单发难穿重甲——"手电筒"梗的来源 | 群众士兵的标配，突出人海 |
| 爆弹枪（Bolter） | 星际战士专属信仰：发射0.75口径**火箭助推爆炸弹**——枪械里的"圣物" | 星际战士身份符号，"非持此枪者不足称神选" |
| 火焰枪（Flamer） | 烧杀异端专用；对恶魔有奇效（净化意象） | 审判官/牧师出场自带 |
| 熔解枪（Melta） | 短距熔穿坦克的热熔武器——"开罐器" | 攻坚戏的反坦克杀招 |
| 等离子枪（Plasma） | 高威力但**会过热炸自己**——高风险神器 | "犹豫就会炸膛"的戏剧点 |
| 链锯剑（Chainsword） | 锯齿震动的近战剑——40K人手一把的近战传统 | 星际战士近战标配，音效极强 |
| 动力武器（Power Sword/Fist） | 分子边缘的能量剑/动力拳——能斩断坦克 | 军官与英雄的等级标识 |
| 灵能武器 | 灵能者的意志具象（蓝焰/雷击/念动） | 反派术士与智库馆长的领域 |

## 二、40K 载具与巨物（尺度感速查）

| 层级 | 代表 | 体量感 |
|------|------|--------|
| 运兵车 | 犀牛（Rhino）、奇美拉（Chimera） | 装甲车级 |
| 主战坦克 | 雷曼·鲁斯（Leman Russ）、罗加·多恩（Rogal Dorn） | 一辆压制一条街 |
| 超重型 | 班刃（Baneblade，"影子之刃"级） | 一辆是一座移动堡垒 |
| 帝国骑士 | Imperial Knight | 两层楼高的单兵机甲 |
| 泰坦 | 战犬→掠夺者→战君→帝王级 | 从四层楼到**移动大教堂**；帝王级泰坦上住着几万乘员 |
| 星舰 | 巡洋舰数公里、主力战舰5-8公里 | 一艘船=一座城市，船员以万计 |

> 剧本提示：40K的战争尺度**永远是超人的**——写"一辆坦克"要写出"一座楼"的压迫感，写"一艘船"要写出"一座城"的荒谬感。

## 三、荷鲁斯之乱时代（30K）装甲型号（星战迷的考据点）

| 型号 | 时代 | 特点 |
|------|------|------|
| MkI 雷霆甲 | 统一战争 | 原始动力甲，无生命维持——太空作战受限 |
| MkII 远征甲 | 大远征早期 | 第一代量产，罗马式浮雕美学 |
| MkIII 铁甲 | 战壕战时代 | 极重极厚，正面无敌的碉堡 |
| MkIV 极大甲 | 大远征巅峰 | 最精密优美——**大叛乱前的"黄金时代"审美** |
| MkV 叛乱甲 | 荷鲁斯之乱中 | 战时拼凑货，各种部件混装——"战争的补丁脸" |
| MkVI 乌鸦甲 | 叛乱后期 | 轻量化原型，暗鸦守卫最爱 |

> 剧本提示：给30K军团戏分阶段换甲型号，是"时代在变坏"的视觉语言——从 MkIV 的华美到 MkV 的拼凑，不用说一句话。

## 四、中古战锤（Fantasy）武器与魔法

- **火器**：火枪（Handgunner）、手炮、大炮——黑火药时代的"哐当感"，配合骑士长枪冲锋=帝国战争美学
- **骑士团**：潘特尼骑士团（豹骑士）、烈焰之心骑士团等——骑士文学+火枪队的混搭
- **八风魔法**（设定核心）：魔法来自环绕世界的八股"风"——天堂（雷云）、火焰、金属（锻金）、生命、光明、天堂/天空、野兽、阴影、死亡；法师只能驾驭一风，**驭八风者会被撕碎**
- **符文锻造**：矮人符文武器（抗魔、永不钝）——矮人祖传、失传中

## 五、西格玛时代（AoS）神兵体系

- **雷铸神兵装备**：西格玛铸神炉锻造的神钢（sigmarite）铠甲；**重铸机制**——战死→灵魂回炉→再战（记忆磨损是悲剧内核）
- **界门（Realmgates）**：连通八界域的巨型传送门——战争围绕它打
- **以太金（Aether-gold）**：卡拉德隆空霸的飞行燃料+硬通货
- **咒铁/魔金**：各类阵营的魔法合金——命名模板"（物质）+（能量）"

## 六、原创化命名公式（发布用）

- 40K枪械：`（神圣前缀）+（功能词）+（铳/枪）`：轰鸣铳、净焰喷枪、熔壳炮
- 近战：`（材质）+（动词）+（剑/斧）`：链锯剑→"咬齿刃"；动力剑→"鸣光剑"
- 载具：`（神/圣词）+（巨物）`：班刃→"堡垒之影"，泰坦→"行 cathedral"→"行圣殿"
- 30K装甲型号：直接用罗马数字+原创名（第七代钢、远征钢、碉堡钢……）
