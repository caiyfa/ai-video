# 战锤黑暗史诗风 — 素材包总览

> 收集时间：2026-10-27 ｜ 来源：联网搜索（Reddit r/Warhammer40k、r/40kLore、萌娘百科、知乎、B站、游民星空等）

战锤（Warhammer）是英国 Games Workshop 公司的桌游/IP 体系，小说由旗下"黑图书馆"（Black Library）出版。分两条主线：

- **战锤40K（Warhammer 40,000）**：遥远未来的太空黑暗科幻，"在冷酷黑暗的遥远未来，只有战争"
- **中古战锤（Warhammer Fantasy / 西格玛时代）**：剑与魔法的黑暗奇幻

对漫剧最有价值的是它的**叙事套路、视觉风格、氛围感**——宏大、压抑、哥特、悲壮。

## ⚠️ 版权红线（先读这个）

**战锤是 Games Workshop 的注册 IP，版权保护极严（Space Marine 一词都注册过商标）。**

- ✅ 可以：学习其风格氛围做**原创化**的"战锤风"作品（自创世界、自创角色、自创名词）
- ❌ 不可以：直接使用其角色形象（荷鲁斯、艾森霍恩等）、原版名词、原版美术做**公开发布/商业**内容
- 本素材包定位是**参考资料**：借鉴叙事结构与美学关键词，产出必须是自己的世界观

原创化示例：不叫"星际战士"，改成"神铸武士团"；不叫"混沌四神"，改成"深渊四主"。

## 推荐使用路径（漫剧小白版）

1. 先读 01 了解故事骨架（荷鲁斯之乱 = 一个完美的"背叛与陨落"悲剧模板）
