# 安格朗（Angron）人物档案

> 建档：2026-10-27 ｜ 内容为自写档案分析，供理解人物结构

## 档案卡

| 项 | 内容 |
|----|------|
| 称号 | 血神之囚、红色天使、第十二军团"吞世者"基因之父 |
| 母星 | 努凯里亚（Nuceria，罗马斗兽场式奴隶世界） |
| 特征 | 颅内钉着**屠夫之钉**（Butcher's Nails）——时刻制造剧痛与狂怒的邪恶植入体；全原体唯一"人格被物理破坏"的兄弟 |
| 武器 | 屠父与屠子（Gorefather & Gorechild 双链斧） |
| 结局 | 荷鲁斯之乱中在努凯里亚上空升格恐虐恶魔原体 |

## 生平时间线

| 阶段 | 事件 |
|------|------|
| 降世与天资 | 婴儿池坠落努凯里亚；他的潜伏灵能是**共情**——能感受他人的痛苦。这是理解他一生的钥匙 |
| 屠夫之钉 | 被高阶奴隶主抓获，强行钉入屠夫之钉——共情能力被物理切断，只剩永不停歇的疼痛与暴怒 |
| 角斗士岁月 | 成为竞技场无敌的奴隶角斗士；与奴隶同伴情同手足 |
| 德什埃利卡之巅 | 率奴隶大起义，最后一战他**拒绝独自逃生**，与两百兄弟背对背迎接死亡——帝皇在此时传送他离开，兄弟们全数被屠杀 |
| 拒绝父皇 | 他恨帝皇："你救的不是我，你杀了我的荣耀。"帝皇强行把他带回军团——这对父子从未和解 |
| 改造军团 | 把劣化版屠夫之钉植入自己的战士——"我的痛，军团一起痛"（扭曲的爱） |
| 影袭战役 | 被罗嘉的仪式利用；重返努凯里亚上空战死后**升格为恐虐恶魔原体**——彻底成为愤怒的化身 |
| 万年后 | 被恐虐当"刀"使唤，偶尔挣脱控制（阿克之门时代曾短暂脱离神控，证明残存的自我仍在最深处） |

## 性格与信条

- **被夺走的共情者**：他本是二十兄弟里最温柔的一个（能感受万物之痛）——被钉子变成怪物。这是全战锤最残忍的"人造反派"
- **求死之志**：他一生唯一的愿望是"死得像个自由人"——连堕落都是别人替他安排的
- 台词语感：几乎不说话；开口即咆哮。他的"台词"应由别人转述（罗嘉的回忆、老战士的口述）——沉默即悲伤

## 人物关系

- **帝皇**：最恨父亲的儿子——恨点最正当（"你救错了"）
- **罗嘉**：仪式的设计者——利用他完成堕落
- **洛泰尔·斯卡尔（Lotara Sarrin）**：人类女舰长，全宇宙唯一敢顶撞他、他从不伤害的人——怪物与勇者的微妙敬重（绝佳配角）
- **卡恩（Kharn）**：最忠诚的"儿子"，同样钉着钉子的行者

## 漫剧改编价值

- **"人造怪物"悲剧本位**：先拍"温柔的孩子"再拍"被钉上钉子"——观众才会为怪物流泪。适合第1集就放出童年共情闪回
- **名场面**：山巅背对背赴死（全战锤最悲壮场面之一，必拍）、被传送走时回头看兄弟被杀（黑化点）、竞技场独战（动作戏）、升格咆哮（终局）
- **叙事禁忌**：别给他太多台词——他的沉默由旁人和闪回讲述，比嘶吼更痛
- **原创化提示**：吞世者→"噬世军团"，屠夫之钉→"痛觉钉"，努凯里亚→"斗兽星"
