| 项 | 内容 |

| 结局 | 纳垢麾下最可怕的信使；把整个死亡守卫"送进"腐朽的人 |

## 生平时间线

| 阶段 | 事件 |
|------|------|
| 巴巴鲁斯边缘 | 平原混血出身，天生灵能却生在"最恨巫术的星球"——从小学会隐藏与忍耐，**怨恨在沉默里发酵** |
| 加入军团 | 因耐毒天赋升入第一连；与莫塔里安互为最信任的左右手——表面如此 |
| 大远征期 | 暗中接触混沌；对父亲（莫塔里安）的恨意一层层压实：他看不起主公的执念，也嫉妒他的强大 |
| **奥雷利安之变** | 泰拉开战前夕，他巧言劝动莫塔里安："抄亚空间近道，抢头功"——全舰队被拖入亚空间**瘟疫隔离带**，全员染上无解瘟疫，生不如死 |
| 献祭舰队 | 莫塔里安昏迷之际，泰丰拒绝一切治疗，代表军团接受纳垢的"慈悲"——**用一整个军团当投名状，把父亲卖成了恶魔原体** |
| 万年后 | 纳垢传令官，战锤40K字面意义的"行走的瘟疫"；率第一连终结者行隐径（亚空间秘道）全银河播撒尸疫 |

## 性格与信条

- **隐忍型背叛者**：与泰丰同类的反派都是"熬"出来的——他等了几十年才等到父亲犯那个致命错误；他从不催促，只负责**在正确的时间说正确的话**
- **自我合理化大师**：他从不认为自己是叛徒——"我只是先接受了不可避免的事"
- 台词语感：温和、耐心、像医生宣读体检报告——越平静越可怕

## 人物关系

- **莫塔里安**：主公+终生仇恨对象——恨他恨灵能者（即恨泰丰的存在本身）
- **纳垢**：新主人——他敬纳垢如"唯一诚实的东西"（腐烂是宇宙唯一不会骗人的真相）
- **死亡守卫普通战士**：被他卖掉又被他带领的"兄弟们"
