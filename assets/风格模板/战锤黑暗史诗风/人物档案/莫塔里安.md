## 生平时间线

| 阶段 | 事件 |
|------|------|
| 巴巴鲁斯童年 | 降生在毒雾平原的人类聚落；高山上巫师军阀**涅卡尔**（Necare）将他掳走当作养子与继承者，在毒雾中磨炼他的耐受力 |
| 复仇之战 | 成年后窃取武器下到平原，教平原人用他的血炼成的毒刃，带领他们仰攻军阀城堡 |
| **被抢走的复仇** | 与养父决战至油尽灯枯之际，帝皇降临替他完成了最后一击——**他一生的"首杀"被父亲抢走**。他要求帝皇承认"是你欠我"，帝皇只回以命令。怨由此种下 |
| 大远征 | 军团以"最能忍"著称；他厌恶灵能与巫术（养父是巫师的创伤） |
| 赫斯特之战 | 与"领主"级敌人作战时期的旧怨重演 |
| 落入纳垢 | 泰拉围城前舰队困于亚空间，全军团染上无可救药的瘟疫；宁死不受灵能治疗、昏迷中被副官泰丰斯"献给"纳垢——**醒来时已成为自己最憎恶的巫术造物** |
| 万年后 | 瘟疫领主，反复尝试反抗纳垢又反复失败——连堕落都不自由 |

## 性格与信条

- **忍耐的化身**：他的军团信条是"我们能忍任何人不能忍之苦"——忍耐最终让他连堕落的命运也忍了下来
- **恨灵能者的灵能者**：他痛恨巫术，自己的灵魂却强大到必然成为巫术的祭品——命运的恶意
- 台词语感：阴郁、布道式、把痛苦当纪律讲

## 人物关系

- **帝皇**：抢走首杀的"恩人"——他从不原谅
- **泰丰斯（Typhus）**：副官→把他献给纳垢的叛徒→万年互恨的瘟疫双煞
- **纳垢**：他称之为"祖父"，恨着又挣不脱的"慈爱"主人
- **贾格泰（原体Motarian line）/白色伤痕可汗**：万年宿敌

## 漫剧改编价值

- **"被抢走的复仇"**：单集结构完美的出身戏——奴隶→起义→最后一击被神抢走。观众立刻懂他为什么恨
- **"最恨巫术者成巫术造物"**：堕落戏的讽刺张力全战锤第一——他不是选择堕落，是**醒来时已经堕落**（恐怖片写法）
- **名场面**：毒雾中的少年复仇军（史诗感开场）、被抢首杀（憋屈名场面）、亚空间瘟疫船（密闭空间恐怖）、苏醒见新躯（终局震撼）
