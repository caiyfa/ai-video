## 档案卡

| 项 | 内容 |
|----|------|
| 称号 | 审判官（Inquisitor），异端审判庭奥菲斯派系 |
| 首秀 | Dan Abnett《艾森霍恩三部曲》：异形（Xenos）→异端（Malleus）→殉道者（Hereticus），40K公认入门书 |
| 时代 | M41（40K现世，荷鲁斯之乱一万年后） |

| 结局 | 活着，但活得越来越久、越来越不像人（灵能延寿）；被审判庭通缉的同时仍在猎杀真正的恶魔 |

## 生平时间线（跨度约两百年）

| 阶段 | 事件 |
|------|------|
| 晋升 | 从调查员（Acolyte）出师成为正式审判官，年轻时的信条：**不惜代价消灭异端**——这个信条将反噬他一生 |
| 异形案 | 追查"教典" necroparadise 案，首次动用恶魔宿主武器"苏尔特之球"击败外星智者奎克修斯——第一次"用魔鬼的力量做正确的事" |
| 一次次滑坡 | 为达目的先后启用受诅咒的巫师伴侣（贝弗琳、内伦·昆德克斯、迈多雷利）、招募原邪教法师作为侧影（黑曜石骑士团事件）……每一步都有理由，每一步都更黑 |
| 失去与黑化 | 挚友米达斯·贝特凯尔被杀；爱人阿丽泽贝丝离世；门徒们一个个或死或叛——他把最后一个敌人关进自己脑中，从此与魔共眠 |
| 被审判 | 被同僚审判庭定性为异端通缉——**他成了自己毕生猎杀的东西**，但没人能取代他去猎杀真正的恶魔 |
| 延续 | 与旧敌奎克修斯的宿命对决跨越三部曲与《帕昆》系列，缠绕两百年 |

## 性格与信条

- **结果主义的滑梯**：他每一步的决策逻辑都是自洽的——"为了阻止更大的恶"。这就是滑坡的定义
- **人的重量**：他痛、他老、他失去——全40K最"人"的主角，也是读者最容易代入的主角
- 台词语感：第一人称回忆录式、冷静自嘲、偶尔崩溃——40K里罕见的"会反思的叙述者"

## 人物关系

- **贝弗琳·洛特文哈拉**：副官→爱人→牺牲品（全系列情感锚点）
- **米达斯·贝特凯尔**：老友，机械师——普通人视角
- **内伦·昆德克斯 / 深红药剂师迈多雷利**：他"改邪归正"的巫师雇员——工具变伙伴变隐患
- **奎克修斯**：外星宿敌——跨越百年的猫鼠局
- **戈兰·拉文诺**：最出色的门徒，后成为独立审判官（续作主角）

## 漫剧改编价值

- **连载主角最佳模板**：单元案（每集一个异端/恶魔案）+ 主线滑坡（他的黑化弧）——可以拍无限季
- **观众悖论设计**：观众永远理解他的每个决定，又永远害怕他的下一个决定——评论区吵不完
- **名场面**：第一次用恶魔武器（滑坡起点，单集结尾绝佳钩子）、雨夜追凶（氛围戏）、被通缉后仍敬着旧审判庭徽（细节催泪）
- **原创化提示**：审判官→"缉异使"，恶魔宿主武器→"封魔之器"——"猎人变猎物"结构原样保留
