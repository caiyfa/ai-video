# 富尔格瑞姆（Fulgrim）人物档案

> 建档：2026-10-27 ｜ 内容为自写档案分析，供理解人物结构

## 档案卡

| 项 | 内容 |
|----|------|
| 称号 | 腓尼基人（The Phoenician）、完美者、第三军团"帝皇之子"基因之父 |
| 母星 | 切莫斯（Chemos，资源枯竭的工业世界——他让它重获美丽） |
| 特征 | 全原体最俊美、白紫配色铠甲、对"完美"病态执念 |
| 武器 | 火刃（Fireblade，拉尔恶魔剑——腐蚀他的一切之始） |
| 结局 | 色孽（Slaanesh）恶魔原体；肉身曾被恶魔夺舍，灵魂受困画中，后世夺回 |

## 生平时间线

| 阶段 | 事件 |
|------|------|
| 切莫斯童年 | 坠落在一个"一切为了生存配给"的灰色工业星；他重建了整个星球的经济与**美学**——连烟囱都是艺术品 |
| 军团之耻→之荣 | 接手时帝皇之子是小军团且有基因缺陷；他以"完美"为军规重建军团，成为大远征礼仪与战力的双重标杆 |
| 拉尔之战 | 征服蛇形异星种族拉尔人，带回一柄**恶魔剑**——剑开始低语："你还能更完美。" |
| 腐化螺旋 | 为追求极致感官与完美，军团渐染享乐异端；他向同袍炫耀战利品时言行渐变 |
| 依斯特万 V | **亲手斩杀最亲密的兄弟铁手费鲁斯·马努斯**——挥剑瞬间他被恶魔彻底夺舍（原著最大黑化瞬间：他事后跪地痛哭，不知道自己做了什么） |
| 夺舍与画牢 | 恶魔完全占据他的身体；他的原初灵魂被囚在一幅肖像画中数千年——"完美者"成了自己躯壳的囚徒 |
| 灵魂夺回 | 后世（小说线）他成功夺回肉身，反手吞噬恶魔——证明他仍是原体中最可怕的存在之一 |
| 万年后 | 色孽恶魔原体；黑暗帝国时代重创复活的基利曼 |

## 性格与信条

- **完美的滑坡**：完美主义每前进一步都合理（更好、更快、更美），终点是"还有什么没体验过"——享乐异端就是完美主义的尽头
- **美丽即原罪**：他是唯一"因为太优秀而毁灭"的原体——没有人逼他，是剑只是给了他"许可"
- 台词语感：优雅、修辞华丽、每句夸赞都像刀——堕落后的台词是"感官诗"

## 人物关系

- **费鲁斯·马努斯**：钢铁之父，他最好的兄弟——被他亲手斩首。全战锤最惨的兄弟戏，无之一
- **圣吉列斯**：另一个"完美"镜像（天使的完美vs蛇的完美）
- **帝皇**：他最想取悦的对象——从未得到他想要的注视
- **法比乌斯·拜尔**：他的"完美 surgeon"传人，比他走得更远的疯狂天才

## 漫剧改编价值

- **"诱惑型黑化"模板**：与佩图拉博（被辜负）、安格朗（被强暴）并列的第三种堕落——**被诱惑**。三种堕落放一起就是一部"叛徒分类学"
