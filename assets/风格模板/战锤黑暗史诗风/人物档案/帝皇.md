## 生平时间线（官方刻意模糊，以下为通行版本）

| 阶段 | 事件 |
|------|------|
| 远古 | 约公元前8000年诞生于安纳托利亚，是最早的人类灵能者集合体；以无数化名隐匿人间万年 |
| 统一战争 | M30：从泰拉起兵，统一太阳系 |
| 原体工程 | 制造二十位基因原体；混沌将其散落银河（帝皇是否预知——永恒悬念） |
| 大远征 | 亲自率队找回原体、收复百万世界；宣传"帝国真理"：**反宗教、反神明、用理性取代迷信** |
| 尼凯亚会议 | 禁止军团使用灵能（马格努斯事件后）；随即返回泰拉，秘密开工**网道工程**（打通灵族网道让人类瞬移） |
| 达文后 | 闻知荷鲁斯叛乱；泰拉围城战爆发 |
| 王座之战 | 与荷鲁斯单挑：不忍下杀手→被重创→观众（虔诚士兵）之死激发怒意→击杀荷鲁斯，自身濒死 |
| 万年至今 | 被安置黄金王座：每日献祭一千名灵能者**维持王座运转**（吊住他破碎的肉体、锚定灵魂、封印宫殿地下的网道裂口）；他的灵能本身是**星炬的光源**，星炬合唱团的万名灵能者作聚焦"透镜"、数月燃尽；被帝国国教奉为神——**他生前最反对的事** |

## 性格与信条

- **彻底的理性主义者**：不信神、禁止造神——因为他知道信仰会喂养亚空间的恶魔（讽刺：人类的信仰最终还是把他造成神并喂养了四神）
- **绝对的功利主义**：为物种存续可以牺牲任何人；对儿子们是"统帅"不是"父亲"——每个原体的悲剧背后都有他的一次"必要的冷酷"（罗嘉的羞辱、马格努斯的利用、安格朗的沉默）
- **永不说出全部真相**：连最爱他的儿子荷鲁斯都被他抹除过记忆——信任问题贯穿整个悲剧
- 台词语感：威严、简短、净价值判断——一开口就是宣判

## 设定辨析：黄金王座 vs 星炬（常被混为一谈）

| | 黄金王座（Golden Throne） | 星炬（Astronomican） |
|--|--------------------------|---------------------|
| 位置 | 泰拉皇宫地下 | 安顿山（皇宫附近山体中的独立设施） |
| 作用 | 维持帝皇生命 + 锚定灵魂 + 封印网道裂口 | 发射银河亚空间导航信标 |
| 能量关系 | **每日一千名灵能者献给王座**，维持王座运转——王座维系着他的性命；不是他"主动吞噬" | **帝皇本人的灵能是光源**；一万名合唱团灵能者是聚焦"透镜"，数月内燃尽——星炬靠他发光，不是反过来 |

> 记忆口诀：**星炬靠他发光，王座靠人吊命**——两件事都吃灵能者，但吃的地方、目的不同。
>
> 近年新设定补充（泰拉围城《终结与死亡》三部曲）：帝皇的存续状态比"机器吊命"更暧昧——他或许随时可以放手，王座既是维生系统，也可能是"锚"甚至"牢笼"。这也是基利曼复活后对王座本质的公开怀疑。写二创时两个方向都成立。

## 人物关系

- **荷鲁斯**：最爱的长子→杀死他的手（互相）
- **罗嘉**：亲手摧毁其信仰（莫纳基亚之辱）——最深的因果
- **马格努斯**：最初想委以网道重任，却在尼凯亚公开折辱他——最错的一步棋
- **圣吉列斯**：最像他"理想"的儿子（美丽、理性、牺牲）
- **莫塔里安**：抢走其"复仇首杀"——结怨
- **机械神教**：以"万机神化身"名义结盟——被造神的开始

## 漫剧改编价值

- **"缺席的神"写法**：全剧他可以只出现三次（任命战帅、尼凯亚、王座之战），每次都改变所有人的命运——少即是多的角色
- **最大讽刺弧**：反神者被造成神。这个闭环适合做片头片尾呼应：同一座王座，第一集有人站着，最后一集有人坐着
- **名场面**：尼凯亚审判（法庭戏）、网道破裂（灾难戏）、王座单挑（父子相残终局）、黄金王座日常（每集片尾固定空镜）
- **原创化提示**：帝皇→"缔造者/永眠之主"，帝国真理→"启蒙圣约"，黄金王座→"沉眠圣座"
