# 佩图拉博（Perturabo）人物档案

## 档案卡

| 项 | 内容 |
|----|------|
| 称号 | 铁铁之主（Lord of Iron）、暴君粉碎者 |
| 身份 | 第四军团"钢铁勇士"基因之父 |

| 结局 | 升格混沌无分恶魔原体，坐镇永恒要塞（Medrengard） |

## 生平时间线

| 阶段 | 事件 |
|------|------|
| 奥林匹亚童年 | 被贵族养父（实为暴君）收养；天赋全开：战术、工程、建筑、雕塑——什么都最好，**却从没被真正看见过** |
| 回归帝皇 | 帝皇只夸了他的工程，随即把军团派去干最脏最累的活：**攻打最硬的堡垒、驻守最偏的星球** |
| 与多恩之怨 | 帝皇把泰拉皇宫的建造给了多恩——佩图拉博视为一生奇耻；兄弟俩互相不服了一辈子 |
| 奥林匹亚之乱 | 养父们为掩盖罪行煽动叛乱；佩图拉博血洗全境、亲手勒死养父，然后**炸毁了奥林匹亚**——连同他青年时雕刻的所有作品 |
| 自弃其名 | 此后不许军团再提家乡，全军改名"钢铁勇士"——他没有名字了 |
| 依斯特万 V | 转投叛军，用最擅长的炮兵轰杀昔日兄弟 |
| 泰拉围城 | 叛军攻城的实际总工程师——"最懂攻城的人攻打最会守城的人"（对多恩的终极对决） |
| 万年后 | 依旧活着的恶魔原体，苦心经营永恒要塞；拒绝一切褒奖——**他要的从来不是奖励，是一句"谢谢"** |

## 性格与信条

- **没被看见的天才**：全宇宙最强的攻城与工程头脑，却被当消耗品使用——他的堕落不是被腐化，是**长期的委屈积成了恨**
- **自我否定式骄傲**：明明渴望认可，嘴上永远说"我不需要"；连恶魔升格他都视作"又一件工具"
- 台词语感：冷硬、精确、每句都带刺；对多恩的每句话都藏着一句"你凭什么"

## 人物关系

- **罗格·多恩**：镜像宿敌（攻方天才×守方天才）——泰拉城墙两边的两个"不会表达的男人"
- **福格瑞姆**：送他铁碎锤的"兄弟"——礼物即羞辱
- **养父们**：一切怨恨的源头——骗他、用他、又背叛他
- **帝皇**：从没对他说过一个"好"字（他这么认为）
