## 生平时间线

| 阶段 | 事件 |
|------|------|
| 巴尔童年 | 降临在被核战辐射摧毁的废土巴尔；翼与美貌让废土人视他为天使；统一巴尔各部族 |
| 血之诅咒 | 巴尔的辐射使他的血脉携带双重诅咒：**红渴**（嗜血冲动）与日后的**黑怒**——他一生隐瞒血脉缺陷的秘密 |
| 大远征 | 军团以"比帝皇真理更优雅"的姿态征战；与荷鲁斯、富尔格瑞姆并称最亲近的三兄弟 |
| 西格努斯陷阱 | 荷鲁斯设计把他诱入被恶魔腐化的西格努斯星系——他直面"红天使"幻象（自己堕落的预兆）并拒绝它；军团险些全军覆没，他带伤且隐瞒伤情赴泰拉 |
| 泰拉围城 | 守城；最终登上复仇之灵号与帝皇同行 |
| 弑弟之死 | 先行独战荷鲁斯——明知打不过，只为消耗他、唤醒他、为父亲争取一击之机。战死。他的死亡脉冲在全部族基因里留下**黑怒**：后世战士会陷入"我就是圣吉列斯临终时刻"的癫狂 |
| 万年余响 | 巴尔的圣血殿中供奉着他的血；帝国把他当救世天使崇拜 |

## 性格与信条

- **完美的代价**：他是"最像结果的原体"——优雅、仁慈、被所有兄弟爱戴；但完美是他的牢笼：隐瞒血脉诅咒、隐瞒西格努斯的伤、独自扛下所有预视
- **知命的勇气**：他早就预见自己的死亡方式，依然去了——"明知不可为"的殉道者，全战锤最纯粹的牺牲者
- 台词语感：温柔、诗性、把死亡说成责任

## 人物关系

- **荷鲁斯**：最爱的哥哥→亲手杀死自己的人（圣经式该隐亚伯倒置）
- **帝皇**：最深的父女式羁绊（他最理解帝皇的孤独）
- **富尔格瑞姆**：嫉妒他完美的兄弟（帝皇之子线）
- **但丁等后世战团长**：万年来背负他的黑怒的子孙们

## 漫剧改编价值

- **"圣人赴死"单集模板**：预知死亡→隐瞒→告别→赴约——四拍结构，一集讲完，催泪炸弹
- **名场面**：巴尔废土展开双翼（出身戏）；西格努斯拒绝红天使幻象（正邪对话）；泰拉城墙展翼剪影（定妆海报级）；复仇之灵号上独自走向荷鲁斯（全宇宙最强催泪长镜头）
- **遗产戏**：黑怒让"他的死亡"在后世每个战士体内重演——一个角色的死亡变成无限集的剧情引擎
- **原创化提示**：圣吉列斯→"圣翼"，血天使→"绯翼武士团"，黑怒→"血契狂涌"
