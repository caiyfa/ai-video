## 生平时间线

| 阶段 | 事件 |
|------|------|
| 童年契约 | 幼年时星系灾难将至，与亚空间存在（奸奇）做交易换力量——**代价：右眼**。"独眼巨人是瞎子"的悲剧起点 |
| 普罗斯佩罗 | 与凡人学者共建学城，收容被帝国歧视的灵能者；军团"千子"由灵能者组成 |

| 帝皇的托付 | 帝皇私召他：计划让他成为**网道工程**的守护者，还为他封住军团的畸变。马格努斯是唯一知道网道存在的原体 |
| 尼凯亚之辱 | 帝皇为平息众议公开禁止一切灵能——马格努斯当场被剥夺话语权。**他不知道禁令只是政治姿态，自己本是内定接班人** |
| 破网传警 | 大远征末期他灵能穿越半个银河向帝皇报警荷鲁斯之乱——**撞碎了帝皇的网道工程**，恶魔涌入泰拉地下。好心办成宇宙级灾难 |
| 普罗斯佩罗之焚 | 帝皇命狼王雷曼·鲁斯"带回"马格努斯——鲁斯理解为"毁灭"。千子军团、学城、千年文明一夜焚尽 |
| 妥协升格 | 为带残部逃离，彻底接受奸奇：升格为恶魔原体，军团全部灵魂永归奸奇 |
| 万年后 | 红色巨魔形态，在原体元素界与鲁斯不死不休 |

## 性格与信条

- **聪明的代价**：全宇宙最聪明的头脑，每一次都选择"我付得起"——最后发现自己从第一笔交易起就在当抵押品
- **知情的傲慢**：他以为看得见因果就能掌控因果——奸奇恰恰是因果之神
- 台词语感：学者腔、自信、越绝望越文雅；"马格努斯什么都没做错"是社区万年梗——他真的什么都没"做"，他只是"存在即被算计"

## 人物关系

- **帝皇**：最信任他的儿子→公开羞辱他→ indirectly 毁了他的一切——父子误解的极限
- **雷曼·鲁斯**：奉命执法的狼王→烧掉他一切的仇人（两人都"照章办事"，最冤的互恨）
- **奸奇**：交易对手/真正的 puppeteer
- **阿扎克·阿里曼**：最恨他的学生（因他执意接受恶魔升格）

## 漫剧改编价值

- **"好心办坏事"天花板**：他是全战锤最好的"错不是他错"悲剧——观众会为他吵起来，评论区即流量
- **名场面**：童年右眼交易（恐怖童话开场）、尼凯亚被夺声（掌掴式羞辱）、破网报警（好心引发灾难的视觉奇观）、普罗斯佩罗焚城（文明毁灭长镜头）、升格恶魔（华丽堕落）
