# 人物档案库 — 战锤黑暗史诗风

> 建档时间：2026-10-27 ｜ 用途：为后续漫剧制作提供人物素材（生平/时间线/关系/画像提示词）
> 内容为基于公开设定的**自写档案与分析**，供理解人物结构；官方美术的版权归 Games Workshop，生图请用原创化提示词

## 档案结构约定

每份人物档案包含六块：

1. **档案卡**：身份/军团/母星/武器/结局速览
2. **生平时间线**：按事件排序的表格（漫剧分集的天然素材）
3. **性格与信条**：人物内核，写台词的依据
4. **人物关系**：师承/兄弟/仇敌——群像戏的连线图
5. **画像参考**：外貌要点 + 即梦/豆包生图提示词（战锤风+原创化各一套）+ 本地官方美术索引（指向我们已下载的PDF）
6. **漫剧改编价值**：这个人物的"集数矿脉"

## 生图工作流（配合画像提示词）

1. 从档案"画像参考"里复制提示词到即梦/豆包
2. 先用**原创化版本**定稿角色设计（避免版权形象，成片安全）
3. 需要官方画风参考时，翻档案里标注的本地PDF（如 `设定集/荷鲁斯之乱/黑书节选/…blood_angels…`），看构图配色，但**别把官方图直接喂给商用流程**
4. 产出的定稿角色图存进 `assets/角色/`，命名 `角色名-场景-编号.png`
