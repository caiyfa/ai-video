# AI漫剧工作区 🎬

用于 AI 漫剧（Motion Comic）创作的个人工作区：从灵感 → 剧本 → 制作 → 发布。

## 目录导航

```
ai-video/
├── AGENTS.md      # AI 助手工作指南（给 AI 看的）
├── docs/          # 📚 知识库（先读 00 总览）
├── ideas/         # 💡 灵感记录区（有灵感就丢这里）
├── projects/      # 🎬 每部作品一个项目目录
└── assets/        # 🎨 跨项目复用的角色/场景/模板素材
```

## 快速开始（小白路线）

1. **有灵感** → 记到 `ideas/`（复制 [灵感模板.md](ideas/灵感模板.md)，一句话就行）
2. **想学习** → 读 [docs/00-AI漫剧入门总览.md](docs/00-AI漫剧入门总览.md)
3. **想做第一部** → 按 [docs/06-新手避坑指南.md](docs/06-新手避坑指南.md) 末尾的"第一周行动清单"走

## 新手工具组合

**豆包**（剧本）+ **即梦AI**（生图/生视频）+ **剪映**（配音/剪辑）——基本免费。
