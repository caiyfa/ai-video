# AI漫剧知识储备清单

> 不需要会画画、不需要专业剪辑背景。核心投入是学习提示词和跑通流程的时间。

## 一、知识模块总表（按优先级排序）

### P0 —— 必须掌握（第一周）

**1. 提示词工程（核心中的核心）**
- 生图万能公式：`场景环境 + 角色动作 + 镜头描述`
- 角色一致性提示词模板的建立与维护
- 负向提示词（排除不要的元素）
- 学到什么程度算过关：能稳定生成"同一个角色在不同场景里脸不变"

**2. 剪辑基础（剪映即可）**
- 时间轴拼接、音画同步、加字幕、加转场、调色
- 导出竖屏视频
- 学到什么程度算过关：能把图片+音频拼成一条带字幕的完整短视频

**3. 平台规则**
- 各平台投稿规范、AI内容标识要求（合规硬性要求）
- 有效观看时长 vs 播放量（分成逻辑）

### P1 —— 重要（第二~四周）

**4. 影视镜头语言**
- 景别：远景/全景/中景/近景/特写——什么时候用什么
- 运镜：推、拉、摇、移——分镜标注必备
- 画面节奏：对话2~3秒/画面，紧张场景0.5~1秒/画面

**5. 叙事/编剧能力（核心竞争力）**
- 悬念钩子设计（每集结尾）
- 起承转合结构
- 对话自然度打磨（AI初稿必须人工精修）
- 前3秒开场抓人技巧

**6. 审美判断**
- 筛选画风统一的素材
- 识别并修复"AI感"瑕疵（六指、脸崩、肢体错乱）

### P2 —— 进阶选学（跑通流程之后）

**7. ComfyUI 本地工作流**：免费无限生图，工作流可控可复用
**8. LoRA 训练**：用自己的角色图训练小模型，深度解决角色一致性
**9. AE 专业动效**：专业级动态效果，学习周期1~2个月
**10. 数据运营**：看后台数据迭代内容方向、A/B测试封面标题

## 二、学习路径建议

```
第1周：提示词基础 + 剪映入门（边学边做一个30秒练手片段）
第2周：完整跑通第一集（用现成简单剧本，别自己写大部头）
第3~4周：补镜头语言 + 编剧钩子，做第2~5集，形成固定流程
之后：看数据迭代内容，按需学P2进阶内容
```

## 三、时间投入参考

| 水平 | 周期 |
|---|---|
| 入门（能做出完整一集） | 1~2周 |
| 熟练（稳定日更/隔日更） | 1~2个月 |
| 专业级（AE/ComfyUI/LoRA） | 额外1~2个月 |
