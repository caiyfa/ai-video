# 新手避坑指南

> 每一条都是别人真金白银试错换来的。

## 六大常见死法

### 1. 工具收集癖 ❌
**症状**：满世界找工具、装了一堆，功能对不上或太难学，直接劝退。
**解法**：锁定「豆包 + 即梦 + 剪映」，每个环节最多1~2个工具，遇到具体瓶颈再换。

### 2. 画风割裂 ❌
**症状**：不同集/不同镜头混用不同生图和视频工具，画风跳戏，像拼盘。
**解法**：同一部作品固定用同一套工具 + 同一套风格提示词模板。

### 3. 上来就想做大制作 ❌
**症状**：想先写世界观宏大的百集大剧，流程没摸熟，第三天弃坑。
**解法**：第一个目标是**完整跑通一集**，哪怕只有30秒、质量粗糙。先有全流程手感，再迭代质量。

### 4. 角色脸崩（一致性失控）❌
**症状**：主角每个镜头换一张脸，观众出戏弃剧。
**解法**：从第一天就建角色设定文档 + 固定角色提示词模板；用即梦的角色参考功能；多抽卡人工筛选。详见 [04-提示词写法与角色一致性.md](04-提示词写法与角色一致性.md)。

### 5. 单镜头生成过长 ❌
**症状**：想一次生成30秒长镜头，AI肢体崩坏率高，返工到怀疑人生。
**解法**：单镜头控制在 **3~15秒**，宁可多切镜头拼接。

### 6. 剧本裸奔（AI初稿直接用）❌
**症状**：AI生成的对话尴尬、剧情前后矛盾、角色降智，被评论区嘲讽。
**解法**：AI出初稿，**人工必须精修对话和逻辑**。叙事能力才是核心竞争力。

## 附加提醒

- **合规**：视频开头加AI内容标识（平台硬性要求）；BGM用合规曲库；别用他人IP角色形象
- **节奏**：平台分成看有效观看时长——结尾钩子决定追更，前3秒决定完播
- **心态**：最大成本是时间和试错；数据不好先改内容，别先怪工具
- **迭代**：每集发布后看评论和后台数据，小步快跑
