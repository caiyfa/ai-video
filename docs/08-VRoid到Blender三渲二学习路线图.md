# VRoid → Blender 三渲二：零基础学习路线图

> 目标：从完全小白到能独立做出动漫风格三渲二短片。
> 前提：每天/隔天投入 1~2 小时，与漫剧主线并行（见文末）。
> 费用：全程软件零费用（VRoid、Blender、VRM插件、Mixamo、剪映全免费；Rokoko动捕单镜头免费）。

## 总览：六个阶段，约 3 个月

| 阶段 | 周期 | 核心产出 | 过关标准 |
|---|---|---|---|
| 0 准备 | 1~2天 | 软件装好 | VRM能拖进Blender |
| 1 捏角色 | 第1周 | 原创角色VRM | 角色卡存入 assets/ |
| 2 Blender基础 | 第2~4周 | 一张静态剧照 | 构图完整的动漫风渲染图 |
| 3 三渲二材质 | 第5~6周 | 动漫感剧照 | 别人看第一反应是"动漫"不是"3D" |
| 4 让角色动起来 | 第7~10周 | 10秒动作片段 | 动作+表情流畅自然 |
| 5 镜头与首部短片 | 第11~12周 | 30秒~1分钟成片 | 完整短片可发布 |
| 6 进阶 | 第13周起 | 按需 | — |

## 阶段0：准备（1~2天）

**装软件：**
1. [VRoid Studio](https://vroid.com)（官网或Steam，免费）——捏动漫角色
2. [Blender](https://www.blender.org)（免费）——3D制作主战场
3. [VRM Add-on for Blender](https://vrm-addon-for-blender.info)——让Blender能导入VRM角色（也可在Blender官方扩展平台直接装）
4. 注册 [Mixamo](https://www.mixamo.com)（Adobe免费账号）——动作库

**硬件**：三渲二用 Eevee 实时渲染，近几年的普通电脑就能跑，不需要专业显卡。

**建立目标感**：先去B站看几个三渲二成品（如《街角奇遇》案例、动漫风混剪），知道终点长什么样。

**过关标准**：在VRoid随便捏个角色导出VRM，成功拖进Blender看到模型。

## 阶段1：VRoid 捏角色（第1周）

**学**：捏脸（五官/脸型）、发型编辑器、服装与材质、表情预设。

**练**：从 `ideas/` 里挑一条灵感，捏出你的**主角**——让学习直接为作品服务。

**过关标准**：导出一个满意的原创角色 VRM，并在 `assets/角色/` 建立角色卡（截图 + 设定说明，提示词模板换成3D后就是"VRM文件+捏人参数"）。

**说明**：VRoid上手极快，这就是为什么不用AI建模做主角——动漫脸质量碾压且完全可控。

## 阶段2：Blender 基础（第2~4周）

**学（只学这条路线用到的，别贪）：**
- 界面与视图操作（中键旋转、滚轮缩放、Shift+中键平移）
- 物体模式 vs 编辑模式的基本概念
- VRM Add-on 导入角色（自动生成人形骨骼映射）
- 场景搭建：导入免费3D资产（BlenderKit等）、地面/天空
- 灯光基础（三点布光）
- 相机与构图（焦段、机位）

**练**：把阶段1的角色放进一个场景，摆个姿势（先不管动画），打光，渲染一张静态图。

**过关标准**：一张构图完整、有氛围的动漫风剧照。

**⚠️ 劝退高发区**：Blender头三天操作反直觉（左键选择而非右键、大量快捷键），是最容易弃坑的阶段。对策：跟一个中文入门系列从头点一遍，别跳。

## 阶段3：三渲二材质（第5~6周）

**学**：
- Eevee 卡通着色（Toon Shader 节点：色阶分层的明暗）
- 描边：Freestyle 或 Grease Pencil 线稿
- 轮廓光（Rim Light）、描边粗细、色阶层数调校
- VRM自带 MToon 材质的用法（VRM Add-on 支持）

**练**：把阶段2的剧照反复调到"像动漫截图"——和你喜欢的一部番的截图并排对比着调。

**过关标准**：拿渲染图给不懂3D的朋友看，第一反应是"这是哪部动漫"而不是"这是个3D模型"。

## 阶段4：让角色动起来（第7~10周，最长阶段）

三条腿走路，按顺序学：

**① Mixamo 动作库（先学这个）**
从Mixamo下载现成动作FBX → 导入Blender → 重定向（Retarget）到VRM人形骨骼（VRM Add-on 的 humanoid 骨骼映射）。
- 常见坑：套用后脚部滑步、髋部高度不对、手指不自然——都需要手动微调，这是正常流程不是失败

**② 视频转动作捕捉（演不出来的动作用这个）**
[Rokoko Vision](https://www.rokoko.com/zh-cn/products/vision)：手机拍自己表演 → 上传云端 → 导出FBX → Blender。
- 免费政策：单摄像头免费，但每段最长约15秒；长动作分段拍再拼接

**③ 关键帧基础（补前两者覆盖不了的夸张动漫演出）**
时间轴、姿势到姿势（pose to pose）、缓入缓出。

**表情口型**：VRM自带表情形态键（喜/怒/哀/惊/眨眼），在时间轴上打关键帧。

**练**：角色走两步 → 停下 → 转头 → 一个表情变化，10秒片段。

**过关标准**：动作流畅无滑步穿模，表情变化自然，渲染出来不尴尬。

## 阶段5：镜头、剪辑与首部短片（第11~12周）

**学**：
- 3D里的运镜：给相机打关键帧就是推拉摇移（呼应 docs/04 的镜头语言知识——那边学的景别运镜这里全部用得上）
- 多镜头分段渲染、序列帧输出
- 衔接剪映：渲染片段 → 剪映拼接、配音（TTS）、字幕、BGM

**练**：30秒~1分钟完整短片（简单对白或无对白都行），从 `ideas/` 挑个简单点子做。

**过关标准**：一部完整成片，发布到平台或至少给朋友完整看完。

## 阶段6：进阶（第13周起，按需选学）

- **Cascadeur**：AI辅助关键帧，做夸张动漫动作
- **AI建模补场景道具**：Tripo/Meshy（见 [07-AI建模与3D动画路线评估.md](07-AI建模与3D动画路线评估.md)）
- **3D控制层 + AI视频混合流**：降抽卡的关键技（同上文档第四节）
- **建3D资产库**：角色、场景、动作库沉淀到 `assets/`，连载时复用

## 新手三大劝退点（提前打预防针）

1. **Blender头三天**：操作逻辑反直觉，弃坑率最高的时刻——跟完一个入门系列就熬过去了
2. **想学所有功能**：只学本路线图点名的功能，建模的深层技巧（雕塑、硬表面）这条路线基本用不到
3. **追求一步到位**：每个阶段只求达到"过关标准"就进下一阶段，回头再精修

## 与漫剧主线的并行策略

- **主线**（本周就开始）：漫剧路线练叙事（[01-制作流程.md](01-制作流程.md)）——叙事能力两条路线通用
- **副线**（每周5~10小时）：按本路线图推进3D
- **交汇点**：完成阶段2~3后，就能开始"3D摆姿势 → 渲染关键帧 → 图生视频"的混合流，**立刻降低漫剧抽卡成本**——不用等全部学完就能回血
