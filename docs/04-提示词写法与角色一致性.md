# 提示词写法与角色一致性

> 这是AI漫剧最核心的技能，也是最容易翻车的环节。

## 一、角色一致性：最大难点及四种解法

**为什么难**：AI每次生图都是"重新画"，没有约束时主角每张脸都不一样，观众立刻出戏。

### 解法1：固定角色提示词模板（新手必学，零成本）

为每个角色写一段**固定不变的描述模板**，每次生图原样带上：

```
【角色模板示例：林晚】
25岁中国女性，齐腰黑色长直发，左侧别一个银色月牙发夹，
琥珀色眼睛，眉尾有一颗小痣，穿米白色高领毛衣和深灰色长裤，
身材纤瘦，气质清冷
```

要点：
- 外貌细节要**具体且独特**（发饰、痣、疤痕等"记忆点"最有效）
- 服装也固定写死（换装剧情时只改服装段）
- 模板存进角色设定文档，每个分镜提示词都复制粘贴

### 解法2：角色参考图绑定（工具功能）

- 即梦AI：角色参考/锁定功能，上传角色图后生成的新图自动保持一致
- Nano Banana Pro：多图参考能力强
- ComfyUI：ControlNet / IP-Adapter，参考图控制姿势和脸部

### 解法3：LoRA 训练（进阶）

用角色的多张图训练一个小型专属模型，一致性最强，适合长期连载的固定主角。需要 ComfyUI 基础。

### 解法4：批量生成 + 人工筛选

同一个镜头多生成几张，只留脸和画风都对的那张。土办法但必须做。

**推荐组合**：解法1 + 解法2 起步；连载稳定后上解法3。

## 二、分镜提示词公式

生产级分镜提示词一般包含以下层级：

```
角色模板（固定）
+ 场景模板（固定）
+ 本镜头剧情与动作（角色在做什么、什么表情）
+ 镜头语言（景别 + 角度 + 运镜）
+ 画面风格（统一的艺术风格描述）
+ 连续性约束（与上一镜头的衔接，如"角色左手拿着伞"）
+ 生成参数（比例 9:16 等）
```

### 示例

```
【镜头12 · 近景】
25岁中国女性林晚（角色模板全文），
雨天的高中教室窗边（场景模板全文），
她侧头望向窗外，眼眶泛红，手里攥着一封被雨打湿的信，
近景，平视角度，浅景深背景虚化，
日系动漫风格，柔和冷色调，电影感光影，
她左手腕上的红色绳子仍然可见（连续性约束），
9:16 竖构图
```

### 景别速查

| 景别 | 画面范围 | 用途 |
|---|---|---|
| 远景 | 整个环境 | 交代场景、开场 |
| 全景 | 人物全身 | 展示动作、人物关系 |
| 中景 | 膝盖以上 | 对话常用 |
| 近景 | 胸部以上 | 表情、情绪 |
| 特写 | 局部（脸/手/物） | 强调关键细节、情绪爆发 |

### 运镜速查

| 运镜 | 效果 | 适用 |
|---|---|---|
| 推 | 靠近，聚焦 | 情绪升级、揭示重点 |
| 拉 | 远离，展示全局 | 收尾、孤独感 |
| 摇 | 左右扫视 | 展示环境、跟随视线 |
| 移 | 平行移动 | 跟随行动 |

## 三、情绪与动作描写

漫剧靠**表情和肢体语言**推动剧情，提示词里的情绪要写具体动作而非抽象词：

- ❌ "她很伤心"
- ✅ "她低着头，肩膀微微颤抖，手指死死绞着衣角"

## 四、文生视频提示词（图生视频环节）

图生视频时提示词重点是**运动描述**，写清楚"什么在动、怎么动"：

```
镜头缓慢推近，女孩的眼泪滑落，雨滴持续敲打窗户，
她的手指轻轻收紧揉皱信纸，头发被风轻轻吹动
```

- 运动幅度描述要克制（"轻轻""缓慢"），大幅运动容易肢体崩坏
- 一次只描述1~2个主要动作

## 五、图生视频 vs 直接文生视频

**结论：先文生图、再图生视频。**

| 方案 | 可控性 | 一致性 | 适用 |
|---|---|---|---|
| 文生图 → 图生视频 | 高（先确认画面满意再动起来） | 好 | **主流推荐** |
| 直接文生视频 | 低（画面全靠抽卡） | 差 | 快速试创意 |
