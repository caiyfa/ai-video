# AI漫剧入门总览

> 本文档是整个知识库的入口，先读这篇建立全局认知。

## 一、什么是 AI 漫剧

AI漫剧（Motion Comic）是介于**漫画和动画之间**的内容形态：

- 用 AI 生成漫画风格的图片（角色、场景、分镜）
- 加上动态效果（图生视频 / 镜头推拉摇移）
- 配上 AI 配音、音效、字幕
- 输出为**竖屏连载短视频**（1080×1920），发布到抖音/快手/B站/小红书等平台

典型样子：抖音上常见的"战神归来""霸道总裁"类漫画式短剧，画面是漫画但会动、有人配音。

## 二、为什么值得做

| 维度 | 传统动画 | AI漫剧 |
|---|---|---|
| 单集成本 | 10~50万元 | 低至千元以内/分钟，个人几乎零成本起步 |
| 制作周期 | 数周~数月 | 1~3天/集 |
| 人力 | 团队 | **一个人可独立完成** |
| 技能门槛 | 需要绘画/专业剪辑 | 不需要会画画，核心是提示词+叙事+剪辑入门 |

## 三、核心流程一句话版

```
剧本 → 角色/场景设定 → 分镜图 → 图生视频 → 配音配乐 → 剪辑合成 → 发布
```

详细展开见 [01-制作流程.md](01-制作流程.md)。

## 四、小白最短路径

1. **工具组合**：豆包（剧本）+ 即梦AI（生图/生视频，有角色锁定功能，新手友好）+ 剪映（配音/剪辑）——基本免费或几十元/月
2. **第一个目标**：完整跑通**第一集**，哪怕只有30秒、画风不完美。先跑通全流程，再谈质量
3. **学习顺序**：提示词写法 → 剪映基础操作 → 镜头语言（景别/运镜）→ 编剧钩子
4. 入门周期约 **1~2 周**，每天抽1~2小时即可

## 五、最重要的三个认知

1. **角色一致性是最大难点**——主角每张脸都不一样就出戏，必须从第一天就建立"角色设定文档"（见 [04-提示词写法与角色一致性.md](04-提示词写法与角色一致性.md)）
2. **叙事能力是核心竞争力**——AI只是工具，观众为故事和悬念买单，不为"AI感"买单
3. **钩子决定生死**——每集结尾必须留悬念，前3秒必须抓住人；平台分成看的是**有效观看时长**，不是播放量
