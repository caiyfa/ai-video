# AI漫剧工具清单

> 原则：**每个环节只用1~2个工具**，跑通流程前不要折腾工具。

## 一、新手推荐组合（首选，基本免费）

| 环节 | 工具 | 说明 |
|---|---|---|
| 剧本 | **豆包** | 免费，中文剧本质量好 |
| 生图 | **即梦AI** | 有角色参考/锁定功能，对新手最友好 |
| 图生视频 | **即梦AI** | Seedance 系列，支持"全能参考"（人物+场景+分镜直接出视频） |
| 配音 | **剪映** | 内置文本朗读，多音色，免费够用 |
| 剪辑 | **剪映** | 字幕、调色、拼接一站式 |

## 三、费用参考

- **起步阶段**：豆包免费 + 即梦免费额度 + 剪映免费 ≈ **0元**
- **长期制作**：即梦等会员 **几十元/月** 量级
- 行业参考：平台制做1分钟内容成本约30元；AI动态漫单分钟生成成本最低600~700元（商用量级）

## 四、选型建议

1. **别贪多**：新手期就锁定"豆包+即梦+剪映"，遇到具体瓶颈再换工具
2. **画风割裂警告**：同一部作品尽量用同一个生图工具 + 同一套视频工具，混用会导致画风不统一
3. **商用注意**：确认所用工具的商用授权条款，保留原创生成记录
