# AI漫剧制作流程（六步详解）

> 标准流水线：剧本 → 角色/场景设定 → 分镜 → 动态化 → 配音配乐 → 后期发布

## 第①步：剧本创作

**做法：**
1. 向大模型（豆包/DeepSeek/Kimi）提供：主题、角色、风格、集数，让它生成剧本初稿
2. **人工精修**：重点改对话（AI写的对话常常尴尬）、剧情连贯性、角色前后一致性
3. 拆分成集，每集 **1~1.5分钟**（3分钟约500~800字对白）

**要点：**
- 每集围绕**一个小冲突**，避免复杂支线
- 结尾必须留**悬念钩子**（这是连载续命的关键）
- 开头前3秒要抓人（直接进冲突，别铺垫）

## 第②步：角色设定 + 场景设定

**角色设定：**
1. 生成角色设定图（正面/侧面三视图更好）
2. **建立角色设定文档**：把角色外貌、发型、发色、服装、配饰写成一段**固定的角色提示词模板**
3. 之后每一次生图都带上这段模板——这是保持"同一张脸"的基础

**场景设定：**
- 生成主要场景设定图（如"雨天的高中教室""赛博朋克街道"）
- 场景描述同样写成固定模板，保证风格统一

**要点：** 批量生成后人工筛选，只保留画风统一的一批素材，宁缺毋滥。

## 第③步：分镜脚本 + 分镜图生成

**分镜脚本：**
- 把剧本拆成镜头列表，每分钟视频约 **5~8 张分镜图**
- 每个镜头标注：景别（远/中/近/特写）、运镜（推/拉/摇/移）、台词、时长

**分镜图生成：**
- 用"文生图"逐镜头生成分镜图
- 分镜提示词结构（详见 [04-提示词写法与角色一致性.md](04-提示词写法与角色一致性.md)）：
  ```
  角色模板（固定） + 场景模板（固定） + 本镜头剧情动作 + 镜头语言 + 画面风格
  ```
- **主流做法是"先文生图、再图生视频"**，比直接文生视频可控得多

## 第④步：图生视频（动态化）

- 把分镜图逐张导入图生视频工具（即梦/可灵等），生成3~15秒的动态片段
- **单镜头控制在3~15秒以内**——片段越长AI出错率越高、返工越难
- 微调动作自然度，加简单转场
- 简化路线：即梦 Seedance 2.0 的"全能参考"可上传人物+场景+分镜直接生成视频，可跳过部分中间步骤

## 第⑤步：配音 + 音效配乐

- 用 AI 配音把台词转成语音（不同角色用不同音色）
- 按配音节奏剪辑、对齐画面
- 添加 BGM 和音效（注意版权，用工具内置的合规曲库）

**节奏参考：**
- 对话场景：2~3秒/画面
- 紧张场景：0.5~1秒/画面

## 第⑥步：后期合成 + 发布

1. 剪映中按分镜顺序拼接时间轴
2. 加字幕、调色、转场、特效
3. 导出 **竖屏 1080×1920 MP4**
4. 开头加 **AI内容标识**（平台合规要求）
5. 结尾加下集预告
6. 多平台分发（抖音1~3分钟；B站可5~10分钟）

---

## 单集制作时间线参考（新手）

| 阶段 | 耗时 |
|---|---|
| 剧本 + 分镜脚本 | 2~4小时 |
| 角色/场景设定（首次，之后复用） | 3~5小时 |
| 分镜图生成 + 筛选返工 | 3~6小时（最耗时、最容易翻车） |
| 图生视频 | 2~4小时 |
| 配音配乐 + 剪辑合成 | 2~4小时 |
| **合计（第一集）** | **1~2天** |

熟练后（设定库已建好）单集可压缩到1天内。
