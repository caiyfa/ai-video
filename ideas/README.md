# 灵感记录区 💡

这里存放随时冒出来的创作灵感。**不求完整，抓到就记**——灵感只需要一句话，发展成剧本是之后的事。

## 使用方法

1. 有灵感时，复制 [灵感模板.md](灵感模板.md) 到本目录，文件名格式：`YYYY-MM-DD-主题.md`（如 `2026-10-26-雨夜信箱.md`）
2. 只填"一句话概括"和"详细描述"就行，其他留空
3. 灵感攒多了（≥5条），可以让 AI 帮忙：
   - 评估哪条最适合做成漫剧（冲突强度、连载潜力、目标人群）
   - 把选中灵感发展成剧本初稿（放进 `projects/` 新项目）
4. 被采用立项的灵感，在状态栏标记 `✅ 已立项 → projects/项目名`；放弃的标记 `❌ 放弃（原因）`

## 灵感评估三问（立项前问自己）

1. **冲突够不够**？——有没有天然的对抗/悬念，能撑起每集一个钩子？
2. **视觉够不够**？——有没有可重复出现的标志性画面/角色（漫剧靠视觉记忆点）？
3. **能不能连载**？——故事能不能拆成每集1~1.5分钟、结尾留钩子的结构？
